## 1.6.0

### Added
- App language selection.
- Theme selection.
- An in-app release notes screen.
- Manual update checks in Settings.

### Changed
- The product creation screen was redesigned: photos were moved to the top, and the overall layout became more convenient.
- Tag management was reworked: recommendations were added, and selecting and organizing tags became more convenient.

### Fixed
- Fixed alphabetical sorting to better respect language-specific rules.
- Fixed issues that could cause backup restore to work incorrectly in some cases.
