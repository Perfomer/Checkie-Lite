# App Functions: управление отзывами через ассистента

## Что это такое

App Functions позволяют управлять отзывами Checkie-Lite голосом или текстом через
on-device ассистента (Gemini). Вы можете попросить ассистента затрекать новый отзыв
или найти уже добавленные — всё это без открытия приложения.

## Требования

- **Android 16 (API 36) или новее** — на более старых устройствах функции недоступны.
- **Gemini с поддержкой App Functions** — интеграция находится в закрытом EAP-доступе.
  На стандартных сборках ассистент может не видеть функции Checkie-Lite.

## Примеры фраз

### Создать отзыв (trackReview)

> «Затрекай дарксайд вкус колы как 10 из 10»
>
> «Поставь 7 из 10 продукту Lemonade бренда Musthave»
>
> «Добавь отзыв: Sprite, без бренда, оценка 6, комментарий "слишком сладкий"»

### Найти отзывы (findReviews)

> «Что я ставил на Darkside?»
>
> «Покажи мои отзывы про колу»
>
> «Какие отзывы у меня есть?»

## Что происходит при создании отзыва

1. Ассистент вызывает функцию `trackReview` с переданными параметрами.
2. В Checkie-Lite создаётся обычный отзыв — он сразу отображается в списке приложения.
3. Рейтинг автоматически приводится к диапазону 0–10 (если вы назовёте 11 — сохранится 10).
4. Ассистент получает подтверждение с данными созданного отзыва.

## Ограничения

Через ассистента можно задать только:

| Поле | Поддерживается |
|---|---|
| Название продукта | да |
| Бренд | да (необязательно) |
| Оценка (0–10) | да |
| Комментарий | да (необязательно) |
| Фото | нет — только в приложении |
| Цена | нет — только в приложении |
| Теги | нет — только в приложении |
| Плюсы / минусы | нет — только в приложении |

После создания вы можете дополнить отзыв фото, ценой и тегами прямо в Checkie-Lite.
